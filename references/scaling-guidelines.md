# Scaling without semantic seams

不要用“35段=1页”“10页=一个 Agent”作为硬阈值。根据实际 token 预算、模型上下文、术语密度和结构决定分块，预留审校/输出容量。
短段直接处理；长篇先全局索引，按方法、结果等章节/小节分块。
不切开段落、表格、算法或定理证明；单块过大时按可解释子单元拆分并保留父 ID。

各 Translator 必须获得：
- 作者已批准的同一 glossary version 与 terms_sha256；未通过 gate 时不开始任何首译；
- 研究对象/贡献/威胁模型或研究设计的简明 context card；
- 相关符号定义、前后段落上下文与统一风格；
- 自己负责的 segment ID 范围与文件写入所有权。
上下文只读，不在合并译稿中重复输出。

准备阶段的结构分析和术语提取可以并行，作者审批之前不能并行启动首译。
审批后互不依赖的片段可以并行首译；不要因固定页数、术语数量或“每章必须一个 Agent”增加无谓角色。
审校可逐块独立进行，最终由主控审查全篇衔接；覆盖全部单元，对数字/限定/新术语加深核对。没有独立工具时串行，不省略正文。

合并后检查：
1. ID 全覆盖且无重复，表格/列表/标题顺序未变。
2. 缩写首次定义与摘要/正文策略一致，符号与时态不漂移。
3. 代词、前后指称、跨节引文与逻辑连接仍有正确指向。
4. 同概念术语一致，局部保留的限定不会在摘要中消失。
5. 词表版本变化后只重译/重审受影响片段，并对合并稿做一次全局术语和缩写扫描。

记录失败/未完成的 Agent，不把缺块默认为已完成。终止或超时后只续做未完成范围。
