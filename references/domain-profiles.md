# Context-specific review profiles

这些是审校重点，不是已经验证覆盖所有学科的知识库；正式译法依赖论文定义与可靠领域来源。
遇到新领域，先建立项目术语和试译，不套用 PA-RAG 词表。

## 计算机 / AI / 密码学

- 冻结系统名、缩写展开、攻击者能力、可信域与计算位置。
- 区分 access structure/policy、KEM decapsulation/payload decryption、witness/proof、raw/transformed embeddings。
- 性能只适用于原文实验配置，独立恢复诊断不自动等同端到端攻击。
- 原文报告零泄漏不自动成为“所有攻击下不存在泄漏”的证明；如果原文已过强，提出 query。
- LSSS 满足关系验证、生成解密辅助量和最终解封装不可合并为“SGX 解密”。

## 医学 / 生物

- 保留研究设计（回顾性/前瞻性、观察性/随机试验）、样本/分析人群、终点、时间点、调整变量与缺失数据口径。
- 保留剂量、给药路径、频次、单位、样本数、效应量、置信区间、p 值、否定与不良事件表述。
- association 不能润色成 causation；没有差异证据不等于等效或无作用。
- sensitivity、specificity、hazard ratio、odds ratio 等不可互换；根据原文定义核验具体译法。
- 原文没有统计显著性结论，不能仅因数值变化添加 significantly。
- 必要时用实际可用的官方术语/原始研究核验，未核验明确说明；不上传患者可识别数据。
- 专业人员需终审临床含义；此 skill 不是医学研究质量认证或临床建议。

## 工程 / 材料 / 其他理工科

- 冻结材料/器件名、工艺步骤、仿真与实测区分、负载/温度/环境条件。
- 单位、量纲、上下限、误差/不确定度、对数尺度、absolute/relative change 精确保留。
- 相关趋势不升级为因果机制，单一配置的结果不泛化为所有工作条件。
- 术语可能跨学科同形异义，按项目概念拆分，不能直接沿用别的论文词表。
