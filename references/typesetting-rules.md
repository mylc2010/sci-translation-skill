# Format and protected-content rules

翻译与换模板是两个任务。默认保留源结构、作者宏和模板，不强制 booktabs、字体、标题大小写、Oxford comma 或特定期刊风格。

## LaTeX

- 保护数学片段、变量大小写、字体族、上下标、宏、环境、引用/标签键。
- 章节标题、caption、算法自然语言注释可翻译；不能因此改函数名、公式或引用归属。
- 引文 key 和出现次数核对；调整语序时引文仍绑定原论断。
- LaTeX 源码中的双引号按项目既有约定（传统方向引号或 csquotes）；code/verbatim/URL 中不做全局引号替换。
- 图表不可断行空格可按模板规范使用，不凭“图1”猜测新 \ref{fig:arch}。
- 公式含中文 \text{...} 时先列受控可翻译范围，保留数学逻辑；未经批准先保护原片段。
- 完整工程才做编译与 unresolved reference 检查；片段只做静态核对并说明未完整编译。
- 常见脚本不能完整解析任意 TeX，带宏展开、复杂环境的工程仍需人工和编译检查。

## Source cleanup

如发现 &#x20;、\textbf{**标题**}、疑似双重转义：
保留原稿；在独立 clean-source 副本记录 old→new 及理由后再翻译。
只净化确认属于粘贴/标记污染的片段，不全局删除字符串；审校以 clean-source 为基线，并保留原始→净化的记录。
不能静默修改科学内容。

## Word / PDF

优先保留 DOCX 原结构或 OOXML 单元映射；HTML 转换只作辅助，须比对公式、脚注、合并单元格和标题。
PDF 提取/OCR 可能漏公式/脚注/双栏顺序；存在不清内容先标记，不能补写。
每个表格单元内容留在同坐标；不能把长单元格移成表外段落，译后也不允许。
仅用户要求时导出 Word/PDF；已有模板优先，并使用实际可用的文档工具。检查渲染，不把“已生成”当成“排版已验证”。
