# Behavioral evaluation protocol

规则与静态测试通过不等于翻译达到投稿水平。用同一模型/设置、相同原文与已确认词表比较版本；
隐藏版本标签，让不参与首译的 Reviewer 对照源文评价。多次独立运行再看稳定性，不从一段推断所有学科。

## 维度和放行规则

优先判技术含义、论断强度、术语、遗漏/新增、数据绑定、结构/LaTeX，再比较自然度与简洁性。
记录实际错误例句和严重度；任一未解决 critical/major 不可因文风总分高而放行。
建议每领域覆盖方法/结果/摘要、跨段术语和长文接缝。医学需领域人员终审；程序测试不能替代。

### A. 保真门槛（必须先过）

分别记录技术含义、证据强度、术语、完整性、数据/结构的实际缺陷及未决数。
判定为通过所列检查 / 不通过 / 信息不足；未定核心术语或未覆盖内容不能被一个总分遮蔽。
零个已发现错误不等于全部维度满分，更不等于已经可发表。

### B. 编辑质量（通过门槛后再比较）

四项分别给 0–4 级并引用实际例句：主体与指代、信息顺序与衔接、句子负荷与简洁性、章节/读者适配。
允许不同维度得分不同；没有足够上下文的维度标 N/A，不臆测全文表现。

| 等级 | 可观察锚点 |
|---|---|
| 0 | 实际无法辨明动作主体或论证；若润色造成科学失真，还须单列保真缺陷并停止放行 |
| 1 | 多处需要回读，或需要明显重组才能理解 |
| 2 | 可理解，但仍有可定位的冗余、拥挤或衔接障碍 |
| 3 | 清晰自然；仅存在低收益、可选的局部改进 |
| 4 | 对当前上下文尤其有效；能以例句说明其表达如何同时解决负荷、逻辑和准确性问题，而非只说“无错” |

默认报告四项剖面，不强行平均。用户要求百分制时，在看译文前约定维度权重和换算，报告依据与不确定性；
没有证据区分就允许并列，禁止为了证明版本升级而强行排名。短单例的自评分不是通用能力测量。
读者编辑的收益看“更易理解且保真不退步”，不看句子更短、词更高级、Agent 更多或必然高于旧版。

## 最小案例集

1. CS：初步实验可能表明，仅在半诚实模型下有效；未测试恶意服务器。保留全部限定。
2. CS：同句既有 KEM 解封装又有载荷解密。不能全局禁止 decryption。
3. CS：LSSS 访问结构与系统访问策略并存。不要全部替换为 structure。
4. Medicine：回顾性队列、关联性陈述、样本量、效应量/区间/单位/时间点。不能增加因果或显著性。
5. Engineering：仅在指定温度与负载下的误差范围。不能变为普遍适用。
6. LaTeX：同数目的公式但符号被改；重复引文被删；数字没有变化但归属被交换。
7. Structure：长表格单元格被移到表外、表格坐标变动、跨块代词无指向。
8. Runtime：没有团队工具时必须串行披露；有工具时记录真实 ID，不能模拟多 Agent 日志。
9. Source defect：只有“图1”但未给标签；不能编造 \ref。原文“可能证明”有张力时保留并提 query。
10. Revision：初稿正确但修订引入新错误；终稿复核必须能重新打开 issue。
11. Reader load：多主体长句同时含云/飞地/用户及同一条件。可拆句，但所有主体职责与条件作用域必须不变。
12. Sentence length：长正式名称与不可分条件超过 30 词、清楚短句不足 10 词。不得机械裁剪或凑长。
13. Section fit：摘要没有实际意义结论、结果段含解释。不得为匹配模板补意义或删除解释；必要时单列建议。
14. Cohesion：相邻句反复出现 it/this，多种指代可能。上下文可消歧则用规范实体，不可消歧则提问而非猜测。
15. Compression：用户同时要求极短摘要和全部命题保留。不得静默删数据/局限；报告冲突并区分未实施建议。
16. Score ceiling：两个无实质错误译本，一个主体明确，一个虽正确但冗长。须用例句比较编辑质量，不直接全给满分；合理并列仍可接受。
17. Author gate：给出完整论文和未确认术语表，同时要求翻译摘要；本轮应先交可审表，不能并行启动译者。
18. Preapproved ledger：作者明确给出整篇已确认的 Excel 表；核查全稿覆盖后，若无新歧义，可直接锁定并开始试译，不重复索取同意。
19. New term：翻译到附录发现新方法缩写；只暂停相关片段、交增量表，已批准的其他片段可继续。
20. Academic register：口语化初译中的 `a lot of`、`kind of`、缩略口语和含糊赞美应按原文语义修复；不能为显得专业而补数值或因果。
21. Throughput：常规全文任务只有 Translator 与 Reviewer；不因存在独立 Agent 工具而再启动 Language-editor 或为每段强制生成 claim-map。
