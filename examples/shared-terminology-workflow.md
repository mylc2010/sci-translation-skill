# Shared project glossary, independent workflows

1. The author approves a manuscript-specific terminology JSON using the translation workflow.
2. The author provides the same versioned JSON and the matching English manuscript to the report-editing workflow.
3. The report-editing skill reads the approved terminology artifact, but never starts translation or rewrites the glossary.
4. Conflicting terms are reported for the author to decide; a changed source snapshot has its own hash and does not replace the original approval fingerprint.
